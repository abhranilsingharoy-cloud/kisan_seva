# KisanSeva Frontend Web App

This is the Next.js 14 frontend application for the **KisanSeva** platform. It provides the user interface for farmers to access crop diagnosis, real-time market prices, weather advisories, and the 7-agent AI advisory system.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **UI Library:** React 19
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Authentication:** Clerk
- **Database / Backend:** Supabase
- **Maps:** Leaflet & MapTiler
- **PWA:** `next-pwa` for Offline-First capabilities

## 🚀 Getting Started

First, install the dependencies from the root monorepo directory:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the application.
